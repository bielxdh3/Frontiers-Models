# Solar System Observatory implementation

The application is local to `E:\GPT-6.1-SOL`. The starting directory was empty and was not a Git repository, so there is no starting branch or commit SHA. No commit, push, pull request, cloud account, backend or remote publication was used.

- Stack: React 19.2.0, Three.js 0.186.1, Vite 7.2.2, Lucide React. One WebGL renderer and one requestAnimationFrame loop. Scientific functions, catalog, presentation mapping, renderer, education, UI and validated persistence are separate modules.
- Core catalog: Sun, eight planets, Moon, 15 other curated moons, five dwarf planets, Vesta, one explicitly hypothetical comet and three schematic regions. The displayed moon selection is not a total census.
- Planetary model: JPL approximate positions, table 1, J2000 mean ecliptic/equinox elements with secular rates. UTC is used as an educational approximation to TDB. Dates are constrained to 1800-01-01 through 2050-01-01 UTC. The Earth–Moon barycenter is approximately separated with the educational lunar position and mass ratio. Kepler solving is bounded to 24 iterations with explicit failure.
- Satellite/small-body model: fixed educational ellipses using documented characteristic distances and periods, deliberately chosen initial phases and simplified orientation. These are not satellite ephemerides. There is no N-body integration, extra perturbation model, light-time correction, precession or physical libration.
- Coordinates: scientific x/y are the J2000 ecliptic plane; z points north. Rendering maps `(x,y,z)` to `(x,z,-y)`. Positional parent frames never inherit parent surface spin. Axial tilt and signed spin do not apply retrograde direction twice.
- Time: 1× means one modeled second per real second; default 86,400×. Direction, nonnegative magnitude and pause are independent. Zero pauses while retaining the nonzero rate. A day is 86,400 seconds, week seven days, demonstration month 30 days, Julian year 365.25 days. Hidden tabs discard the hidden interval. An abnormal frame gap is capped at 250 ms; slow software rendering can consequently advance more slowly than the nominal rate.
- Exploration mapping: heliocentric display distance `21*(r/AU)^0.42`; display radius `0.16+0.76*(R/6371 km)^0.44`; satellite display distance `3*parentDisplayRadius+2.2*sqrt(r/384400 km)`. Ring radii remain tied to planet radii. True scale uses 21 display units per AU for sizes and distances alike. Screen locators are separate from physical disks.
- Comparison uses one linear diameter scale; the optional logarithmic diameter stage is explicitly labeled. The combined true-scale laboratory forces a linear axis. Numerical measurement, light-time, ratios, gravity and orbital periods never read display geometry. Temperature values use kelvin with reference context.
- Experiments own independent parameters and an independent demonstration clock, advanced inside the one rendering loop. Seasons use a geometric horizon with polar handling; phases use idealized illumination geometry. Eclipse cones and outer-system regions are schematic and do not predict real event circumstances.
- Data references accessed: 2026-10-22. Primary routes are in `src/data.js`; mission dates and sources in `src/content.js`. Saturn's 274-moon count is a dated March 2025 reference; unverified changing totals are unavailable rather than invented current values.
- Assets: 11 locally bundled 2K color/cloud maps, Solar System Scope / INOVE, CC BY 4.0, based on NASA imagery/data with saturation adjustments and reconstructed terrain. Explicitly illustrative procedural materials cover unmapped bodies and failed resources. Seeded procedural stars have no real star names or claimed celestial coordinates. Manrope is bundled from Google Fonts under its SIL Open Font License. Icons use the Lucide ISC license.
- Recovery: local catalog/comparison/labs remain usable without WebGL; a lost context preserves state and exposes restoration. Texture errors keep a body-specific material. Versioned bounded imports reject malformed identifiers, dates, camera vectors and experiment ranges; import preview applies atomically. Storage denial keeps an in-memory session with export. Scene exports exclude notes and collections. No telemetry, authentication, analytics or secret is used.
- Photography: PNG crops the rendered canvas to the selected aspect, deliberately composites optional HTML-equivalent body labels, date/model caption and attribution. The 2× option is explicitly resampled, bounded to 3072 px wide and 12 megapixels. Video is capability-dependent, user-initiated, capped at 15 seconds and scene-only. Speech synthesis is optional, off initially, canceled between tour stops and complete through text when unavailable. Offline installation is not configured; bundled loaded content has no live data dependency.
- Quality: shared geometry, cached textures, bounded trail history, capped pixel ratio, reduced star counts, explicit resource disposal and hysteretic adaptation. Opening and closing SVG laboratories does not allocate another renderer. High/medium/low pixel-ratio caps are 2/1.5/1. Adaptation requires three slow windows to reduce and eight fast windows to increase.

Local verification uses `npm test`, `npm run build` and `npm run test:browser`. The browser runtime and test output are contained inside this project. Test downloads are disposable generated samples. Browser evidence and limitations are recorded separately from mathematical checks in `test-results/` and `docs/ACCEPTANCE.md`.
