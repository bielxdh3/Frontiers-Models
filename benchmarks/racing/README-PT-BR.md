# Racing-bench

**Benchmark 002 — jogo completo de corrida arcade cinematográfica para navegador.**

O prompt oficial para implementação é o [Racing-bench V2.6](./prompts/racing-v2.6.md). Ele descreve uma experiência 3D original e completa para execução independente em um espaço de trabalho isolado. Os requisitos e as permissões estão no próprio prompt.

## Anexos obrigatórios para execução

**Toda nova execução do Racing-bench V2.6 deve receber os dois arquivos:**

1. [Prompt completo V2.6](./prompts/racing-v2.6.md).
2. [Nota obrigatória de ferramentas](./prompts/execution-tooling-clarification-v1.md), permitindo as skills operacionais e ferramentas de navegador necessárias para construir, inspecionar e testar o próprio projeto.

**Não** enviar somente o prompt com uma instrução adicional de proibição absoluta de skills. A nota não libera consulta a outros projetos, código externo, memórias, arquivos privados, conectores pessoais ou delegação a outra IA.

Se uma execução já começou, enviar a nota como esclarecimento adicional e registrar quando foi enviada, sem alegar que fazia parte do início. O prompt V2.6 original permanece imutável.
