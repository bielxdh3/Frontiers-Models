# ASSET-LICENSES

Everything that is not code written for this project is **CC0 1.0 (public domain dedication)** or MIT (three.js). No car model, no building, no tree, no
track and no music was downloaded: cars, houses, church, lighthouse, bridge, trees, props, rocks, the sea and the circuit are generated by code.
The reference screenshots of the benchmark (`refs/`) are **not part of the build**: the game never loads them (the server refuses `/refs/`); they are
only read by `npm run verify` to draw the side-by-side comparison images in `verification/compare/`.

Raw source files are listed with their original page so that each one can be checked. Derived files (cut, pitch-flattened, cross-faded loops) are
produced by `tools/audio-build.py` from the originals in `assets/audio/raw/fs/` (see README, "Rebuilding the audio").

## Synthesised by the project

* UI sounds (navigation, confirm, 3-2-1, GO, finish flag, lap) are short oscillator tones generated in `src/audio/audio.js` (allowed by the brief for UI/ambience).
* The reverb impulse response (bridge deck / village streets) is generated noise shaped by an exponential decay, in `src/audio/audio.js`.
* All textures that are not Poly Haven (sign atlas, sponsor boards, rubber, straw, foliage atlases, road marking/rubber lines, start banner, metal/cloth grain) are drawn in code (`src/render/proctex.js`, `src/render/props.js`, `src/render/vegetation.js`, `src/render/materials.js`).
