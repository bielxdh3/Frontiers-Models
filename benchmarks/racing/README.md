## Required execution attachments

**Every new Racing-bench V2.6 execution must receive both documents:**

1. [Complete V2.6 prompt](./prompts/racing-v2.6.md).
2. [Mandatory tooling clarification](./prompts/execution-tooling-clarification-v1.md), permitting the operational skills and browser tools needed to build, inspect, and test the assigned project.

Do **not** send only the prompt with a separate blanket instruction to avoid all skills. The clarification does not permit other projects, outside code, memories, private connectors, unrelated files, or AI delegation.

For an already-running task, send the clarification as an explicit follow-up, and document when it was supplied; do not claim that it was part of the original task. Keep the V2.6 prompt immutable.
